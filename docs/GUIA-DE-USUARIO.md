# Guía de Usuario - Sistema de Preconteo Electoral

## Introducción

Bienvenido al Sistema de Preconteo Electoral de Colombia.

**Versión:** 1.0.0  
**Última actualización:** Julio 2026

---

## Para Coordinadores (Web)

### Acceso al Sistema

1. Abra su navegador web
2. Ingrese a: https://app.tudominio.com
3. Inicie sesión con sus credenciales

### Dashboard Principal

El dashboard muestra en tiempo real:
- Resultados parciales
- Progreso de mesas
- Alertas del sistema
- Mapa de participación

### Validar Actas

1. Vaya a la sección "Actas"
2. Filtre por estado "REPORTADA"
3. Revise detalles del acta
4. Decida: Validar o Rechazar

### Alertas del Sistema

⚠️ Advertencias (Amarillo):
- Diferencia entre votantes y boletas
- Votos en blanco altos

🚨 Críticas (Rojo):
- Votos > Votantes
- Candidato con 100% de votos

## Para Testigos (PWA)

### Instalación

#### Opción 1: PWA (Recomendado)
1. Abra Chrome/Safari en su móvil
2. Vaya a: https://pwa.tudominio.com
3. Menú → "Agregar a pantalla de inicio"

#### Opción 2: APK Android
1. Descargue el APK
2. Instale la aplicación
3. Abra "Testigos Electorales"

### Primer Inicio de Sesión

⚠️ La primera vez DEBE tener conexión a internet

1. Abra la aplicación
2. Ingrese email y contraseña
3. Toque "Iniciar Sesión"
4. La app descargará datos necesarios

### Registrar un Acta

1. Toque "Registrar Acta"
2. Complete información de la mesa
3. Ingrese votos por candidato
4. Tome 2-3 fotos del acta
5. Toque "Guardar Acta"

### Sincronizar

Las actas se sincronizan automáticamente con internet.

Para sincronizar manualmente:
1. Vaya a "Pendientes"
2. Toque "Sincronizar Todo"

### Consejos para Fotos

✅ Haga esto:
- Buena iluminación
- Enfoque nítido
- Números legibles
- 2-3 fotos por acta

❌ Evite esto:
- Fotos borrosas
- Sombras sobre números
- Recortar el acta

## Preguntas Frecuentes

**¿El sistema es seguro?**
Sí. Usa encriptación SSL/TLS y autenticación JWT.

**¿Funciona sin internet?**
La PWA de testigos sí. El dashboard web requiere conexión.

**¿Puedo usar mi propio celular?**
Sí, instale la PWA o el APK en cualquier dispositivo Android.

**¿Cuántas fotos puedo tomar?**
Máximo 5 fotos por acta.
